# Workflows

The repo is intentionally reduced to three operator workflows:

1. `live.md`: real bot entry and Tokyo deployment.
2. `replay.md`: replay, audit, and live-vs-replay convergence.
3. `research.md`: parameter search and candidate generation.

Historical notes were moved to `docs/archive/`.
Historical one-off scripts may still exist under `scripts/`, but the stable entrypoints are under `scripts/workflows/`.
