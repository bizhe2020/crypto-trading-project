# QQQ Drawdown Risk Feature Dictionary

This is the shadow-only LightGBM feature map for predicting whether QQQ suffers a future 10-trading-day max drawdown of at least 5%.

## Label

| Field | Formula | Notes |
| --- | --- | --- |
| `target_drawdown` | `min(low[t+1:t+10]) / close[t] - 1 <= -5%` | Uses only future rows for the research label. The latest live row has no label. |
| `future_drawdown_pct` | `(min(low[t+1:t+10]) / close[t] - 1) * 100` | Stored for audit, not used as a feature. |

## Real Breadth Features

Generated by `scripts/fetch_qqq_constituent_breadth.py` from the Nasdaq-100 constituent list and Nasdaq historical OHLCV endpoint. The StockAnalysis QQQ holdings table is used only to add current weights when available.

| Feature | Formula |
| --- | --- |
| `qqq_breadth_constituent_count` | Constituents with usable close on date. |
| `qqq_breadth_data_coverage_pct` | Usable constituents / universe size. |
| `qqq_breadth_advancers_pct` | Percent of constituents with positive 1d return. |
| `qqq_breadth_above_ma20_pct` | Percent above MA20. |
| `qqq_breadth_above_ma50_pct` | Percent above MA50. |
| `qqq_breadth_above_ma200_pct` | Percent above MA200. |
| `qqq_breadth_new_high_20_pct`, `qqq_breadth_new_high_60_pct` | Percent at rolling 20d/60d highs. |
| `qqq_breadth_new_low_20_pct`, `qqq_breadth_new_low_60_pct` | Percent at rolling 20d/60d lows. |
| `qqq_breadth_median_ret_5d` | Median constituent 5d return. |
| `qqq_breadth_ret20_dispersion` | Cross-sectional std of constituent 20d returns. |
| `qqq_breadth_weighted_above_ma20_pct`, `qqq_breadth_weighted_above_ma50_pct`, `qqq_breadth_weighted_above_ma200_pct` | Weight-aware breadth if weights are available. |
| `qqq_breadth_top10_weight_pct` | Current top-10 holdings concentration if weights are available. |
| `qqq_breadth_top10_abs_contribution_share_pct` | Share of absolute weighted 1d movement from top-10 holdings. |

Limitations: constituent breadth uses the current Nasdaq-100 universe by default, so historical breadth is survivorship-biased. Use it as a shadow risk input until a point-in-time constituent source is added.

Macro limitation: FRED observation dates are not always market-available dates. `scripts/fetch_fred_macro_indicators.py` applies conservative release lags for weekly, monthly, and quarterly macro series before forward-filling them into the daily model table. This avoids the largest look-ahead problem, but it is still less precise than a true economic-release calendar with real-time vintages and consensus surprises.

Current model policy: macro features are wired but not enabled by default, because the first walk-forward check with the full macro layer reduced raw ranking AUC. Use the macro layer as an audited experiment until feature selection and release-calendar handling are tightened.

Macro groups can be enabled selectively with:

```bash
python3 scripts/qqq_drawdown_risk_model.py \
  --macro-path data/public/macro/fred_macro-1d.feather \
  --macro-groups dollar_credit_commodity_vol
```

Available groups: `rates`, `inflation`, `labor_growth`, `dollar_credit_commodity_vol`, `all`.

## Probability Calibration

The model uses walk-forward training with an embargo between labelled training rows and test rows. Each fold trains LightGBM on the earlier block, calibrates probabilities on the trailing calibration window, and only then scores the next test window.

| Method | Implementation | Notes |
| --- | --- | --- |
| `platt` | Logistic regression on raw-probability logits | Default; tends to be smoother for the current sample size. |
| `isotonic` | `sklearn.isotonic.IsotonicRegression` | Available by flag; can over-compress sparse low-risk regions to exact 0 or 1. |
| `none` | Raw LightGBM probability | Diagnostic only; not recommended for exposure gates. |

## Model Table Schema

| Column | Type | Role |
| --- | --- | --- |
| `date` | timestamp UTC | Trading day. |
| `target_drawdown` | float/binary | Research label. Missing for latest unlabeled rows. |
| `future_drawdown_pct` | float | Label audit value. Not a feature. |
| `qqq_close` | float | Audit value. Not a model feature. |
| `<feature_name>` | float | Model feature. LightGBM handles missing optional features. |

## Shadow Report Schema

`scripts/qqq_drawdown_risk_model.py` writes:

| Field | Meaning |
| --- | --- |
| `latest_shadow_signal.date` | Latest row date. |
| `latest_shadow_signal.risk_score_0_100` | Calibrated probability times 100. |
| `latest_shadow_signal.model_prob_10d` | Calibrated 10d drawdown probability. |
| `latest_shadow_signal.raw_prob_10d` | Raw LightGBM probability before calibration. |
| `latest_shadow_signal.suggested_exposure` | Shadow-only exposure suggestion, not live execution. |
| `latest_shadow_signal.risk_bucket` | `low`, `elevated`, `high`, or `severe`. |
| `latest_shadow_signal.top_drivers` | Importance-weighted z-score drivers aligned with historical risk direction. |
| `latest_shadow_signal.missing_data_flags` | Optional data gaps that affected the run. |
